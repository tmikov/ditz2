Verified. After removing dz/issues:

  dz list   -> "no issues", exit 0
  dz doctor -> "no problems found", exit 0
  dz add    -> dz: internal error: ENOENT ... .md.tmp-...

Exit 3 INTERNAL is for bugs in the tool, not for a recoverable project state. listIssueIds returns [] when the directory is absent, and doctor has no check for it.

Fix: doctor reports the missing directory, and writeIssue creates it rather than crashing.
