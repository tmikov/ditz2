readIssue does syntax (parseIssue) but never validateIssue. That split was deliberate for the parser: it must round-trip whatever is on disk, including files written by a newer version.

Two halves, with different answers:
- doctor should absolutely run validateIssue over every issue. Obvious, doing it.
- readIssue validating is a design question, and I would argue against: it would make dz show fail on the very file you are trying to inspect, which is when you most need to see it.
