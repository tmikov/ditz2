tsconfig.json sets include to src/**/*.ts and then excludes src/**/*.test.ts, so npm run typecheck checks no test file. Vitest transpiles without typechecking, so a type error in a test is invisible and "typecheck clean" means less than it appears.

Add a tsconfig.test.json covering src/**/*.test.ts and tests/**/*.ts, and run both.
