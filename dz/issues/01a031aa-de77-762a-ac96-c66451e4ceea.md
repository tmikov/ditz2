findIssue calls loadAllIssues, which reads and fully parses every file, then re-reads the one that matched. That is O(n) parses per lookup, and every write now re-parses too.

Irrelevant at the scale this tool targets. Noted so the cost is a decision rather than a surprise if someone points it at a few thousand issues. Filenames are the ids, so prefix resolution could work from the directory listing and parse only the winner.
